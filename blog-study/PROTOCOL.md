# Blog follow-up protocol v1

English BANKING77, source and split hashes in data-manifest.json. Existing 30-message pilot excluded. Labels are dataset annotations, not new LLM judgments. No claims of uncontaminated pretraining or production traffic.

Systems: Jev 1.13 TypeSafe; GPT-OSS-120B Cerebras low reasoning; Mercury 2.5 Inception no reasoning; Gemini 3.8 Flash Google AI Studio standard low reasoning. Same class definitions, ID mapping, user input, and core instruction. LLMs also emit a self-reported correctness probability; Jev supplies probabilities natively. This is a pipeline comparison, not identical confidence semantics. Prompt and label order remain fixed after development; no model-specific accuracy tuning.

Counts per system: 50 development, 200 threshold-selection, 500 held-out test, 50 fixed timing repeats. Repeats never contribute additional accuracy samples. All 77 intents represented in held-out subset. Exact normalized duplicate text removed before sampling; no semantic-duplicate guarantee.

Scheduling: same host, up to four concurrent requests, exactly one outstanding per endpoint; rotate model dispatch order deterministically per input. No retries. 30-second timeout, 1024-token output cap includes reasoning. Complete response wall time includes deserializing the response and local schema validation. Retain full response body without headers or credentials. Capture billed usage, cache details where exposed, requested and returned model/provider identifiers. No Flex, priority or batch routing.

Budget: $10 cumulative on this study, including development and failures. Durable reservation written before network call; concurrent reservations count; settle using reported bill, otherwise usage estimate, otherwise full reservation. Unsettled reservation blocks automatic resumption. Account/provider bill is authoritative; forecast not a guaranteed bill. Stop on four consecutive transport/schema failures from one endpoint to diagnose. This operational guard was amended after development exposed three intermittent Mercury HTTP 502 errors; those failures remain in the records, without retries. Never silently change code/data contract during a run.

Accuracy: correct/500 including failures as incorrect. Macro-F1 over 77 classes. Show invalid/timeout/refusal rates separately. Nearest-rank median and p95 on valid completed test calls, with terminal failures reported rather than dropped. Timing repeats separately.

Confidence: Jev chosen-label probability and native confidence separately; LLM verbalized probability. Native confidence is a ranking score, not assumed P(correct). Validate numeric [0,1]. Preserve complete Jev distribution. Error detection AUROC and grouped-tie average precision use error as positive and negative confidence as detection score. AP baseline is observed error prevalence. Zero errors or zero correct predictions => discrimination undefined.

Calibration: binary correctness Brier for selected-label / verbalized probability only. Reliability plots five fixed equal-width probability bins with counts and Wilson 95% intervals. Display native confidence correct/wrong distributions without relabeling native values as correctness probabilities. Sparse bins explicitly marked. No fitted calibrator.

Deferral: use only 200 threshold-selection examples, never test. Candidate thresholds 0, .05, ... 1. Choose greatest calibration acceptance subject to empirical accepted error <=5% and at least 30 valid accepted cases. Tie => lowest cutoff. No qualifying threshold => abstain all. Fit Jev native and probability cutoffs separately. This rule has no finite-sample safety guarantee. Freeze thresholds file before first held-out request. Report held-out accepted count/500, errors/accepted, Wilson 95% intervals. Compare accept-all and random deferral expected risk at same coverage; target not met is a result. Descriptive risk-coverage curves must not be used to revise the operational cutoff. All failures deferred, included in overall accuracy denominator.

Uncertainty: paired source-example bootstrap, 2000 replicates, seed 20260920, stratified by original intent to preserve sampling design, for accuracy and paired differences versus Jev. All model comparisons exploratory; no superiority/noninferiority or production-risk guarantees. One date/host only; cached service behavior may affect timing. Stop at prespecified sample size, do not sample until a winner appears.

Outputs: model table; accuracy/latency/cost charts; confidence correctness distributions; reliability; risk-coverage; frozen cutoff outcomes; raw sanitized records; paired error audit; revised blog draft. Keep every failed call and disagreement. No human-ground-truth claims beyond original dataset provenance.
